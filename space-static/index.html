DecisionTune 1.0

A 395M decision model. Give it a state, a question and options: it picks one and gives a probability for each. Or ask a yes/no question and get P(yes).

These are real outputs from DecisionTune 1.0 (PyTorch backend, laptop CPU), recorded on 2026-10-04. To try your own text, run it on your machine:

pip install decision-tune
decision-tune ask "Is the customer asking for a refund?" --state "The order arrived broken. I want my money back."

# or with Docker
docker run --rm -p 8000:8000 ghcr.io/decision-tune/decision-tune serve --host 0.0.0.0 --yes
